# SQL Analysis

This folder contains SQL queries used to analyze household electricity consumption using summary tables imported into MySQL.

## Analysis Performed

- Sorted hourly electricity consumption to identify peak usage periods.
- Compared average power consumption across weekdays and months.
- Identified the highest-consumption days.
- Compared yearly average power consumption.
- Compared weekday and weekend usage using conditional aggregation.
- Filtered high-consumption days using `WHERE`.
- Calculated counts, minimums, maximums, and averages using aggregate functions.

## SQL Concepts Practiced

`SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `COUNT()`, `AVG()`, `MIN()`, `MAX()`, `ROUND()`, and `CASE WHEN`.

## Dataset

UCI Individual Household Electric Power Consumption dataset.

Note: These queries analyze imported summary tables, not the original minute-level dataset directly.
